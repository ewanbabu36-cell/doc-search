# Database Migrations

This directory contains SQL migration files generated by Drizzle Kit.

## Commands
* Generate migration: `pnpm --filter @docsearch/database db:generate`
* Run migrations: `pnpm --filter @docsearch/database db:migrate`

## Schema Isolation
* `core.*` -> Shared Multi-tenancy, Users, Roles, Auditing
* `company.*` -> Phase 1: Company Platform entities
* `clinical.*` -> Phase 2: Partner / Clinic / Hospital Platform entities
